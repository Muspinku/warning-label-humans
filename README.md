make.fun entry for **Warning Label for Humans: One Line, Big Laugh** — the safety warning label that should come printed on every human being, in one line of at most 160 characters.

## The entry

> WARNING: Runs on caffeine and spite. Do not operate before coffee. Says 'I'm fine' while on fire. Starts projects at 2am, abandons them by Tuesday.

147 characters, one line.

## Run it

```sh
node main.ts
```

Node 22+, standard library only. Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), with no trailing newline, then verifies the written bytes round-trip exactly.
